Enregistrer ce tirage dans l'application

Le résultat est gravé dans la page « Résultats », protégé par un code d'accès. Avec le lien et le code, chacun peut y chercher son nom et retrouver son parrain ou ses filleuls. Le tirage enregistré est verrouillé : on ne peut pas le refaire par erreur. Pour l'envoyer, utilisez le bouton Partager de l'application (en haut à droite) et choisissez un accès par lien.

Choisissez un code d'accès (au moins 6 caractères). Les noms seront chiffrés : sans ce code, personne ne peut les lire, même avec le lien. Donnez le code aux étudiants avec le lien. Un tirage déjà enregistré sera remplacé et ce tirage sera verrouillé.
Un nouveau tirage remplacera les résultats actuels.

Le dernier tirage est gardé dans ce navigateur : si la page se recharge pendant la cérémonie, les résultats restent les mêmes.
